# Nesting in Sass

Nesting lets you write CSS in a more structured, readable way by placing selectors _inside_ the elements they belong to.  
If you're comfortable with HTML structure, nesting will feel natural and keeps related styles grouped together.

---

## ⭐ Why Nesting Is Useful

Without Sass, you’d write:

```css
header {
  background: lightblue;
}

header button {
  background: purple;
}

header p {
  color: #333;
}
```

This works… but becomes messy as your stylesheet grows.

With nesting, you keep everything inside the `header` block:

```scss
header {
  background: lightblue;

  button {
    background: purple;
  }

  p {
    color: #333;
  }
}
```

Sass compiles it into the same CSS — just more organized.

---

## 🧩 Basic Nesting Syntax

```scss
.parent {
  property: value;

  .child {
    property: value;
  }
}
```

Compiles to:

```css
.parent {
  property: value;
}

.parent .child {
  property: value;
}
```

Nice and clean.

---

## 🎯 Example from the Video

```scss
header {
  background: lightblue;

  button {
    background: $primary-button;
  }
}
```

Sass outputs:

```css
header {
  background: lightblue;
}

header button {
  background: #yourColorHere;
}
```

## 🎛 Using the Ampersand (`&`)

The `&` symbol refers to the **parent selector,** super helpful for:

### ✔️ Pseudo-classes

```scss
button {
  background: $primary-button;

  &:hover {
    background: red;
  }
}
```

### ✔️ Pseudo-elements

```scss
button {
  &::after {
    content: "→";
  }
}
```

### ✔️ States or variations

```scss
button {
  &.active {
    border: 2px solid black;
  }
}
```

This compiles to:

```css
button.active {
  border: 2px solid black;
}
```

---

## 📌 Nesting Depth — Keep It Reasonable

It’s tempting to go wild:

```scss
header {
  nav {
    ul {
      li {
        a {
          span {
            /* too deep! */
```

Try to avoid going past 2–3 levels.
Over-nesting leads to heavy selectors and hard-to-maintain code.

---

## ✔️ Summary

Nesting helps you:

- Keep related styles grouped together
- Match styles to HTML structure naturally
- Write cleaner, less repetitive CSS
- Use the `&` symbol for pseudo-classes, pseudo-elements, and modifiers

It’s one of the first Sass features that instantly improves your workflow.
