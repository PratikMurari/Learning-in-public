# Operators in Sass

Sass allows you to perform **math operations directly in your styles**, making it easier to calculate sizes, spacing, and layout values dynamically.

This is something plain CSS can’t do (except in `calc()`), and it makes Sass much more flexible.

---

## ⭐ Why Operators Are Useful

Imagine manually calculating:

- widths like `100% - 20%`
- spacing like `1.5rem * 3`
- adjusting colors or positions with half or double values

In Sass, you just write the math, and it compiles to CSS.

---

## 🧩 Supported Operators

| Operator | Meaning                     |
| -------- | --------------------------- |
| `+`      | Add                         |
| `-`      | Subtract                    |
| `*`      | Multiply                    |
| `/`      | Divide _(Sass rules apply)_ |
| `%`      | Modulo (remainder)          |

---

## 🎯 Example From the Video

The instructor demonstrates a simple calculation:

```scss
width: 100% - 20%;
```

Sass compiles it as:

```css
width: 80%;
```

---

## 🔧 Basic Examples

### Addition

```scss
padding: 10px + 5px; // 15px
```

### Subtraction

```scss
width: 100% - 50%; // 50%
```

### Multiplication

```scss
font-size: 1rem * 1.5; // 1.5rem
```

### Division

```scss
margin: 20px / 2; // 10px
```

### Modulo

```scss
$result: 10 % 3; // 1
```

---

## 🎛 Combining Operators With Variables

```scss
$base-spacing: 8px;

.card {
  padding: $base-spacing * 2; // 16px
  margin-top: $base-spacing * 3; // 24px
}
```

This helps build consistent spacing scales.

---

## ⚠️ Important Note About `/` Division

Sass has _special rules_ for `/` because CSS also uses `/` (e.g., in `font`, `calc()`, gradients).

### Safe version:

```scss
$half: 20px / 2; // works as math
```

### If Sass thinks you meant CSS and not math:

Use parentheses:

```scss
margin: (20px / 2); // ensures calculation happens
```

---

## ✨ Operators + Functions

Sass allows mixing math with functions:

```scss
$box-size: 100px;

.box {
  width: $box-size + 20px; // 120px
  height: $box-size * 1.5; // 150px
  border-radius: $box-size / 10; // 10px
}
```

Great for fluid sizing across multiple components.

---

## ✔️ Summary

Operators let you:

- Perform math directly in your styles
- Simplify spacing, sizing, and layout calculations
- Build dynamic design systems
- Avoid hardcoding values everywhere

They make your SCSS more flexible, expressive, and maintainable.
