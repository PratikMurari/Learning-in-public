# Partials & Imports in Sass

Partials let you split your styles into smaller, organized files.  
Imports let you bring those files back together into a single compiled CSS output.

Think of partials as “chapters” of your stylesheet — easier to navigate, easier to maintain.

---

## 🧩 What Is a Partial?

A partial is just an SCSS file whose **filename begins with an underscore**:

```

_variables.scss
_header.scss
_mixins.scss

```

The underscore tells Sass:

> “Don’t compile this file on its own — it’s a helper file.”

This keeps your CSS output clean.

---

## 📁 Example from the Video

The instructor moved header styles into:

```

_header.scss

```

And variables into:

```

_variables.scss

```

Both were stored in the `styles` folder.

---

## 📥 Importing a Partial

Inside your main stylesheet (often `style.scss`), you pull them in with:

```scss
@import "variables";
@import "header";
```

### Important notes:

- You **omit the underscore** (`_variables.scss` → `'variables'`)
- You **omit the extension** (`.scss` is assumed)
- Sass automatically finds the file

---

## 🗂 Example Folder Structure

```
styles/
  _variables.scss
  _header.scss
  style.scss
```

Your main `style.scss`:

```scss
@import "variables";
@import "header";
```

Sass compiles this into **one** CSS file (e.g., `style.css`).

---

## ✨ Benefits of Partials

| Problem                 | Solution via Partials                          |
| ----------------------- | ---------------------------------------------- |
| Huge, messy single file | Break styles into logical pieces               |
| Difficult to find code  | Each feature gets its own file                 |
| Hard to collaborate     | Multiple people can work on different partials |
| Repeated patterns       | Store mixins, variables, utilities separately  |

---

## 🔧 Common Partials You Might Create

- `_variables.scss` – color palette, spacing, fonts
- `_mixins.scss` – reusable mixins
- `_buttons.scss` – button styles
- `_header.scss` – header section
- `_footer.scss` – footer section
- `_globals.scss` – resets, base typography

This is entirely up to your project needs.

---

## ⚠️ A Note About `@import` (Important!)

The video uses `@import` because it’s simple.
However, **modern Sass recommends `@use` and `@forward` instead**.

For learning (and matching the video), `@import` is perfectly fine.

---

## ✔️ Summary

Partials & imports let you:

- Organize your Sass into smaller files
- Keep your main file clean and readable
- Control exactly which files combine into the final CSS
- Follow a more modular, scalable workflow

They’re one of Sass’s biggest advantages over regular CSS.
