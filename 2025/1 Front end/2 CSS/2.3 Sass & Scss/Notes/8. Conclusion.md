## 🎉 What You Learned

### **Variables**

- Store reusable values (colors, spacing, fonts)
- Update design system values in one place
- Example:
  ```scss
  $primary: #6c5ce7;
  ```

### **Nesting**

- Keep related selectors grouped
- Match your HTML structure naturally
- Use `&` for hover, focus, and modifiers

  ```scss
  button {
    &:hover { ... }
  }
  ```

### **Partials & Imports**

- Break your stylesheet into readable sections
- Use `_file.scss` and `@import 'file'`
- Great for organizing large projects

### **Mixins**

- Reusable “functions” for repeated patterns
- Accept parameters for customization

  ```scss
  @include flexCenter;
  ```

### **Extend**

- Inherit styles from another selector
- Useful for shared component patterns

  ```scss
  @extend header;
  ```

### **Operators**

- Use math directly in your styles
- Perfect for spacing, layout, and scaling

  ```scss
  width: 100% - 20%;
  ```

- You write **less code**
- Your stylesheets become **more organized**
- Updating designs becomes **much easier**

- Your CSS becomes **more scalable** for real projects

## 🧪 Mini Sass Cheat Sheet

A compact reference summarizing the essentials:

```scss
// VARIABLES
$primary: #6c5ce7;
$spacing: 1rem;

// NESTING
header {
  button {
    &:hover {
      background: darken($primary, 10%);
    }
  }
}

// PARTIALS & IMPORTS
// _variables.scss
@import "variables";

// MIXINS
@mixin flexCenter($direction: row) {
  display: flex;
  justify-content: center;
  align-items: center;
  flex-direction: $direction;
}

@include flexCenter(column);

// EXTEND
.contact {
  @extend header;
}

// OPERATORS
width: 100% - 20%;
padding: $spacing * 2;
```
