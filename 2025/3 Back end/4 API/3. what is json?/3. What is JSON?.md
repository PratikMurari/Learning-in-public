## What Is JSON?

**JSON** stands for **JavaScript Object Notation**.

JSON is:

- A **data format**
- Used to **send data over the internet**
- **Readable by humans**
- **Efficient for machines**

Despite the name, JSON is:

- Language-independent
- Supported by almost every programming language

---

## JSON vs JavaScript Objects

### JavaScript Objects

- Use **key–value pairs**
- Keys do **not require quotes**
- Can contain:
  - Strings
  - Numbers
  - Arrays
  - Nested objects

Example (JavaScript object):

```js
const person = {
  name: "Jack Bauer",
  education: {
    degree1: "UCLA",
    degree2: "UC Berkeley",
  },
};
```

---

### JSON Structure

JSON looks almost identical but has **stricter rules**:

Key differences:

- **All keys must be strings**
- Keys **must be in double quotes**
- Data is **serialized as a string**

Example (JSON):

```json
{
  "name": "Jack Bauer",
  "education": {
    "degree1": "UCLA",
    "degree2": "UC Berkeley"
  }
}
```

---

## Why JSON Is Used

### Serialization

- JSON is a **serialized string**
- Serialization = converting structured data into a compact format
- Makes it easy to:

  - Transfer over the internet
  - Store efficiently
  - Send between different systems

### IKEA Flat-Pack Analogy 🪑

- JavaScript Object → fully assembled wardrobe
- JSON → flat-pack version
- Easier to transport
- Can be reassembled later

---

## JSON Readability Problem

When JSON is transferred:

- It is often **minified**
- All data appears on one line
- Hard for humans to read

### Solution: JSON Viewers

A **JSON visualizer** helps:

- Expand & collapse nested objects
- Understand deeply nested structures

Recommended tool:

```
https://jsonviewer.stack.hu
```

## Converting Between JSON and JavaScript

### JSON.stringify()

**Purpose:** Convert a JavaScript object → JSON string

```js
JSON.stringify(jsObject);
```

- Used when:

  - Sending data over the internet
  - Sending API responses

- Creates a flat-pack string representation

---

### JSON.parse()

**Purpose:** Convert JSON string → JavaScript object

```js
JSON.parse(jsonString);
```

- Used when:

  - Receiving data from APIs
  - Needing to work with the data in code

---

## Accessing Parsed JSON Data

Once parsed, JSON behaves like a normal JS object:

```js
data.ingredients.protein.name;
```

- You can:

  - Access properties
  - Loop through arrays
  - Drill into nested objects

## Key Concepts Reinforced

- JSON is a **string representation of data**
- APIs send data in JSON format
- JSON must be **parsed** before use
- Once parsed, it behaves like a JS object
- Deep nesting requires:

  - Careful inspection
  - Familiarity with arrays & objects

---

## Key Takeaways

- JSON = JavaScript Object Notation
- Used for data exchange across the web
- Serialization = flattening data
- Parsing = reassembling data
- JSON viewers help understand complex structures
- Understanding JSON is essential for API work
