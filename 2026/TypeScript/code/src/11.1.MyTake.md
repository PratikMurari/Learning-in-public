# Arrays, Tuples & Enums — JS/TS Cheatsheet

## 🔷 Array

An **ordered, mutable collection** of elements — all typically the same type.

```ts
// JavaScript
const fruits = ["apple", "banana", "cherry"];

// TypeScript
const fruits: string[] = ["apple", "banana", "cherry"];
const nums: Array<number> = [1, 2, 3];
```

- ✅ Length can change (`push`, `pop`, `splice`)
- ✅ All elements share the same type
- ✅ Best for **lists of homogeneous data**

---

## 🔶 Tuple

A **fixed-length array** where each position has a known, specific type.

```ts
// TypeScript only
const point: [number, number] = [10, 20];
const entry: [string, number] = ["age", 30];

// Destructuring
const [x, y] = point;
const [label, value] = entry;
```

- ✅ Fixed length — positions are meaningful
- ✅ Each index has its **own type**
- ✅ Best for **structured pairs/records** (e.g. `[key, value]`, `[x, y, z]`)
- ⚠️ TypeScript only — JS has no native tuple type

---

## 🟣 Enum

A **named set of constant values**, used to represent a fixed group of options.

```ts
// TypeScript only — numeric (default)
enum Direction {
  Up, // 0
  Down, // 1
  Left, // 2
  Right, // 3
}

// String enum (preferred — more debuggable)
enum Status {
  Pending = "PENDING",
  Active = "ACTIVE",
  Inactive = "INACTIVE",
}

const current: Status = Status.Active; // "ACTIVE"
```

- ✅ Gives **readable names** to fixed sets of values
- ✅ Great for **state machines, roles, directions, categories**
- ⚠️ TypeScript only — use `const` objects in plain JS:

```js
// JavaScript equivalent
const Status = Object.freeze({
  Pending: "PENDING",
  Active: "ACTIVE",
  Inactive: "INACTIVE",
});
```

## ⚖️ Quick Comparison

| Feature    | Array              | Tuple                   | Enum                       |
| ---------- | ------------------ | ----------------------- | -------------------------- |
| Length     | Dynamic            | Fixed                   | Fixed (defined at compile) |
| Types      | Uniform            | Per-position            | Named constants            |
| Mutability | Mutable            | Mutable (but typed)     | Immutable                  |
| JS support | ✅ Native          | ❌ TS only              | ❌ TS only                 |
| Best for   | Lists of same type | Structured data records | Named sets of options      |

---

## 🧠 When to Use What

| Scenario                              | Use     | Why                                                                 |
| ------------------------------------- | ------- | ------------------------------------------------------------------- |
| List of user names                    | `Array` | Unknown length, all items are the same type                         |
| RGB color values `[255, 0, 128]`      | `Tuple` | Always exactly 3 numbers, each position has a fixed meaning         |
| Function returning `[data, error]`    | `Tuple` | Two values of different types returned together in a known order    |
| Days of the week / app states / roles | `Enum`  | A closed, finite set of named options — not a list, not a structure |
| API response items                    | `Array` | Variable number of same-shaped objects from a server                |
| `[latitude, longitude]` coordinates   | `Tuple` | Exactly 2 numbers where order and position carry specific meaning   |
