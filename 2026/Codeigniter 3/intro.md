# CodeIgniter 3

CodeIgniter 3 is a lightweight, legacy PHP framework that uses the Model-View-Controller (MVC) pattern. 
Designed for developers who need a simple toolkit to create full-featured web apps, it features a gentle learning curve, exceptional performance, and virtually zero configuration.

## Key FeaturesSmall 
- Footprint: The entire framework core is remarkably lean, keeping your applications fast and efficient.
- MVC Structure: Separates your application's logic (Controller), data (Model), and presentation (View).
- Built-in Libraries: Includes convenient helpers and libraries for sessions, form validation, email, file uploads, and encryption.
- Database Abstraction: Features a Query Builder that allows for safe and convenient database interactions
