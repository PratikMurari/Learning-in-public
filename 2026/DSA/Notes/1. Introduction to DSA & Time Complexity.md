# 📘 Lecture 1: Introduction to DSA & Time Complexity

## 🔹 1. What is DSA?

- Data = Information (raw facts)
- Example:
  - Numbers, names, marks
  - Ingredients for tea (milk, sugar, water)

👉 Without data, you cannot build any program.

---

### 📌 Data Structure

- Way to **store and organize data**
- Helps in easy access and usage

### 🧱 Types of Data Structures:

#### ✅ Linear Data Structures

- Array
- Linked List
- Stack
- Queue

#### ✅ Non-Linear Data Structures

- Tree
- Graph

👉 Example:

- Water can be stored in:
  - Glass (for drinking)
  - Bucket (for bathing)
- Same data → different structures based on need

---

### 📌 Algorithm

- Step-by-step instructions to solve a problem

👉 Example:
Making tea = algorithm

1. Boil water
2. Add tea leaves
3. Add milk & sugar

👉 Different people → different steps → different results

## 🔹 4. What is Time Complexity?

- Used to measure:
  👉 How fast an algorithm runs

---

### ❌ Wrong Ways to Measure:

- ❌ Checking clock time
- ❌ Counting lines of code

👉 Because:

- Different computers → different speeds
- Background apps affect performance

---

### ✅ Correct Way:

- Use **Mathematical Analysis**

---

## 🔹 5. Important Concept: Dominating Term

👉 Focus only on the **most time-consuming part**

### Example:

- 1 lakh + 10 → ignore 10
- 10 sec + 1 sec → ignore 1 sec

👉 Rule:

- Ignore smaller terms
- Keep the biggest (dominant) term

---

## 🔹 6. Order of Growth (Important Ranking)

From fastest to slowest:

```

O(1) < O(log n) < O(n) < O(n²) < O(n³) < O(2ⁿ)

```

👉 Smaller = Better performance

---

## 🔹 7. Types of Time Complexity (Math Functions)

| Type        | Example  |
| ----------- | -------- |
| Constant    | O(1)     |
| Linear      | O(n)     |
| Quadratic   | O(n²)    |
| Cubic       | O(n³)    |
| Logarithmic | O(log n) |
| Exponential | O(2ⁿ)    |

---

## 🔹 8. Asymptotic Notations

### 📌 1. Best Case → Ω (Omega)

- Minimum time

### 📌 2. Average Case → Θ (Theta)

- Average time

### 📌 3. Worst Case → O (Big-O)

- Maximum time (MOST IMPORTANT)

👉 In interviews → always use **Big-O**

---

## 🔹 9. Constant Time Complexity → O(1)

### When?

- No loops
- No recursion

### Example:

```python
x = 5
print(x)
```

👉 Runs once → constant time

---

## 🔹 10. Linear Time Complexity → O(n)

### When?

- Single loop

### Example:

```python
for i in range(n):
    print(i)
```

👉 Runs n times → O(n)

---

### 🧠 Trick:

- One loop → O(n)

---

## 🔹 11. Multiple Independent Loops

```python
for i in range(n):
    print(i)

for j in range(n):
    print(j)
```

👉 O(n + n) = O(n)

👉 Ignore constants

---

## 🔹 12. Nested Loops → O(n²)

```python
for i in range(n):
    for j in range(n):
        print(i, j)
```

👉 n × n = n²

---

### 🧠 Trick:

- Loop inside loop → multiply

---

## 🔹 13. Triple Nested Loop → O(n³)

```python
for i in range(n):
    for j in range(n):
        for k in range(n):
            print(i, j, k)
```

👉 n × n × n = n³

---

## 🔹 14. If-Else Case

```python
if condition:
    O(n²)
else:
    O(n)
```

👉 Take worst case → O(n²)

---

## 🔹 15. Logarithmic Time → O(log n)

### When?

- Input reduces by half every step

---

### Example:

```python
while n > 1:
    n = n // 2
```

👉 Sequence:
n → n/2 → n/4 → n/8 ...

👉 Time = log n

---

### 🧠 Trick:

- Divide by 2 → O(log n)
- Multiply by 2 → O(log n)

---

## 🔹 16. Quick Rules (Super Important 🚀)

### ✅ Rule 1:

- No loop → O(1)

### ✅ Rule 2:

- One loop → O(n)

### ✅ Rule 3:

- Nested loops → O(n²)

### ✅ Rule 4:

- Divide/multiply → O(log n)

### ✅ Rule 5:

- Independent loops → Add → O(n)

### ✅ Rule 6:

- Nested loops → Multiply

### ✅ Rule 7:

- Always pick **worst case**

---

Code contains:

O(n²)  ← biggest term
