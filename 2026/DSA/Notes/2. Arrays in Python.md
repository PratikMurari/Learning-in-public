# 📘 Lecture 2: Arrays in Python (Chai aur DSA)

## 🧠 What is an Array?

An **array** is a data structure used to store multiple values in a **single variable**.

### Key Idea:

- Stores elements in **continuous memory**
- Usually contains **similar type of data**

---

## ⚠️ Python vs Other Languages

| Feature   | C / C++ / Java | Python        |
| --------- | -------------- | ------------- |
| Size      | Fixed          | Dynamic       |
| Data Type | Same type only | Mixed allowed |
| Memory    | Manual         | Automatic     |

👉 In Python:

- Arrays can be **dynamic (size can change)**
- Can store **different data types** (but not in `array` module strictly)

---

## 📦 Ways to Create Arrays in Python

### 1. Using `array` Module

```python
import array

arr = array.array('i', [1, 2, 3, 4])
```

### 🔑 Type Codes:

- `'i'` → Integer
- `'f'` → Float
- `'u'` → Unicode character

👉 Important:

- Only **same data type allowed**
- If wrong type → error

---

### 2. Using NumPy (Better Approach ✅)

```python
import numpy as np

arr = np.array([1, 2, 3])
```

### Why NumPy?

- More powerful
- Supports **multi-dimensional arrays**
- Faster operations

---

## 🔢 Indexing

```python
arr = [10, 20, 30]

print(arr[0])  # 10
```

👉 Index always starts from **0**

---

## 🔁 Traversing an Array

### Method 1: Using Index

```python
for i in range(len(arr)):
    print(arr[i])
```

### Method 2: Direct Loop (Recommended ✅)

```python
for x in arr:
    print(x)
```

---

## ➕ Insert / Update / Append

```python
arr.insert(1, 50)   # Insert at index
arr.append(100)     # Add at end
arr[2] = 200        # Replace value
```

---

## ❌ Deleting Elements

```python
arr.pop(2)     # Remove by index
arr.pop()      # Remove last element
arr.remove(50) # Remove by value
```

---

## 🔄 Reverse Array

```python
arr.reverse()
```

---

## ✂️ Slicing (VERY IMPORTANT 🔥)

```python
arr = [1,2,3,4,5,6]

print(arr[2:5])   # [3,4,5]
print(arr[::-1])  # reverse
```

### Rule:

- Start → Included ✅
- End → Excluded ❌

---

## 🔍 Searching in Array

```python
arr.index(45)
```

👉 Returns index of element
👉 If not found → Error

---

## 📥 Taking Input from User

```python
n = int(input("Enter size: "))
arr = []

for i in range(n):
    x = int(input())
    arr.append(x)
```

---

## 📑 Copying an Array

```python
new_arr = [x for x in arr]
```

### With Operation:

```python
new_arr = [x * 2 for x in arr]
```

👉 This is called **List Comprehension** (important for interviews)

---

## 📊 NumPy Special Functions

### 🔹 linspace (equal division)

```python
np.linspace(10, 20, 5)
```

👉 Divides range into equal parts

---

### 🔹 arange (step-based)

```python
np.arange(10, 20, 2)
```

👉 Like range() but for arrays

---

### 🔹 zeros / ones

```python
np.zeros(5)
np.ones(5)
```

---

### 🔹 full

```python
np.full(5, 10)
```

👉 Creates array filled with same value

---

## 🧱 Multi-Dimensional Arrays

### 1D Array

```python
[1,2,3]
```

### 2D Array (Matrix)

```python
[[1,2,3],
 [4,5,6]]
```

### 3D Array

```python
[
 [[1,2],[3,4]],
 [[5,6],[7,8]]
]
```

### Concept:

- 2D = collection of 1D arrays
- 3D = collection of 2D arrays

---

## ⚠️ Important Notes

- Python arrays are **dynamic**
- Index starts from **0**
- Slicing is **very important for interviews**
- NumPy is preferred for advanced usage
