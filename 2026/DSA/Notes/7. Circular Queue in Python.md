# 📘 Circular Queue in Python

## 🔹 What is a Queue?

- A **Queue** follows **FIFO (First In, First Out)**.
- Insert → from **rear**
- Delete → from **front**

---

## 🔹 Problem with Normal Queue (Array-Based)

In languages like C/C++/Java:

- Array size is **fixed**
- No shifting happens after deletion

### ❌ Issue:

Even if there is space at the front, we **cannot reuse it**

Example:

```

[1, 2, 3, 4, 5]
Delete 1, 2 → front moves ahead

Now space exists at start, but cannot insert there!

```

👉 This wastes memory

---

## 🔹 What is Circular Queue?

A **Circular Queue connects the last position back to the first**

➡️ Think like a **circle / loop**

So when rear reaches end, it comes back to start

---

## 🔹 Why Circular Queue?

✅ Reuses empty space
✅ Avoids memory wastage
✅ Efficient for fixed-size arrays

---

## 🔹 Real-Life Examples

- 🔄 Round Robin Scheduling (CPU)
- 🎵 Audio buffers (like Spotify)
- 🔫 Revolver (bullets rotate)
- 🎮 Passing games / musical chairs

---

## 🔹 Key Concepts

### 1. Initial State

```
front = -1
rear = -1
```

👉 Means queue is empty

---

### 2. Empty Condition

```
front == -1
```

---

### 3. Full Condition

```
(rear + 1) % size == front
```

👉 Means next position of rear is already occupied

---

### 4. Single Element Condition

```
front == rear
```

👉 Only one element left

---

## 🔹 Important Trick: Modulo Operator (%)

Used to make queue circular

### Formula:

```
(rear + 1) % size
(front + 1) % size
```

👉 Keeps index within range (0 to size-1)

---

## 🔹 Enqueue (Insertion)

### Steps:

1. Check if queue is full
2. If empty:

```
front = rear = 0
```

3. Else:

```
rear = (rear + 1) % size
```

4. Insert element at rear

---

## 🔹 Dequeue (Deletion)

### Steps:

1. Check if queue is empty
2. If only one element:

```
front = rear = -1
```

3. Else:

```
front = (front + 1) % size
```

---

## 🔹 Python Implementation

```python
class CircularQueue:
 def __init__(self, size):
     self.size = size
     self.items = [None] * size
     self.front = -1
     self.rear = -1

 def enqueue(self, value):
     # Check full
     if (self.rear + 1) % self.size == self.front:
         print("Queue is full")

     # First element
     elif self.front == -1:
         self.front = self.rear = 0
         self.items[self.rear] = value

     # Normal case
     else:
         self.rear = (self.rear + 1) % self.size
         self.items[self.rear] = value

 def dequeue(self):
     # Check empty
     if self.front == -1:
         print("Queue is empty")

     # One element
     elif self.front == self.rear:
         print("Deleted:", self.items[self.front])
         self.front = self.rear = -1

     # Normal case
     else:
         print("Deleted:", self.items[self.front])
         self.front = (self.front + 1) % self.size
```

## 🔹 Key Takeaways

- Circular Queue solves **memory waste problem**
- Uses **modulo operator** for circular behavior
- Same logic as normal queue + **wrap-around**
- Very important for:
  - OS scheduling
  - Buffers
  - Real-time systems

---

## 🚀 Final Tip

👉 Always remember:

```
Use % size whenever you increment front or rear
```

👉 That’s the core idea of Circular Queue!
