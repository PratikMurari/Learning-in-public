# Queue & Deque in Python

## 🔹 1. What is a Queue?

A **Queue** is a data structure that follows:

👉 **FIFO (First In, First Out)**

- The element added first is removed first.

### 📌 Real-Life Example

Think of a **line at a ticket counter**:

```
Front → [1] [2] [3] [4] ← Rear
```

- Person 1 came first → leaves first
- New people join from the **back (rear)**

---

## 🔹 2. Key Idea

- Insert → always at **rear (end)**
- Delete → always from **front (start)**

---

## 🔹 3. Why Use Queue?

Queue is used in:

- API request handling
- Task scheduling (OS)
- Printer queue
- Rate limiting systems
- BFS (graph algorithms)

---

## 🔹 4. Basic Operations in Queue

### ✅ 1. Enqueue (Insert)

- Add element at **rear**

```
Enqueue(10)
Enqueue(20)
Enqueue(30)

Queue → [10, 20, 30]
```

### ✅ 2. Dequeue (Delete)

- Remove element from **front**

```
Dequeue() → removes 10

Queue → [20, 30]
```

### ✅ 3. isEmpty()

- Check if queue is empty

---

## 🔹 5. Important Rule

❌ Cannot insert/delete from middle
✔ Only front & rear operations allowed

---

## 🔹 6. Queue Implementation in Python

👉 We use **list** (dynamic array)

### 📌 Step 1: Create Queue Class

```python
class Queue:
    def __init__(self):
        self.items = []
```

### 📌 Step 2: Check Empty

```python
def is_empty(self):
    return len(self.items) == 0
```

### 📌 Step 3: Enqueue (Insert at End)

```python
def enqueue(self, value):
    self.items.append(value)
```

### 📌 Step 4: Dequeue (Remove from Front)

```python
def dequeue(self):
    if self.is_empty():
        raise Exception("Queue is empty")
    return self.items.pop(0)
```

---

## 🔹 7. Example Usage

```python
q = Queue()

q.enqueue(10)
q.enqueue(20)
q.enqueue(30)

print(q.dequeue())  # 10
print(q.dequeue())  # 20
print(q.dequeue())  # 30
```

---

## 🔹 8. Behind the Scenes (Important Concept)

In other languages (C/C++/Java):

- Use **array + pointers**
- Two variables:
  - `front`
  - `rear`

### 🧠 Logic:

- Initially: `front = rear = -1`
- First insert → both become `0`
- Enqueue → `rear++`
- Dequeue → `front++`

---

## 🔹 9. Python Advantage

✅ No need to manage:

- front pointer
- rear pointer
- overflow condition

Because:

- List grows automatically
- Elements shift automatically

---

## 🔹 10. What is Deque?

👉 **Deque = Double Ended Queue**

- Insert & delete from **both ends**

### 📌 Allowed Operations

| Operation         | Allowed? |
| ----------------- | -------- |
| Insert front      | ✅       |
| Insert rear       | ✅       |
| Delete front      | ✅       |
| Delete rear       | ✅       |
| Middle operations | ❌       |

---

## 🔹 11. Deque Implementation in Python

### 📌 Step 1: Class

```python
class Deque:
    def __init__(self):
        self.items = []
```

### 📌 Step 2: Insert at Rear

```python
def insert_rear(self, value):
    self.items.append(value)
```

### 📌 Step 3: Insert at Front

```python
def insert_front(self, value):
    self.items.insert(0, value)
```

### 📌 Step 4: Delete from Front

```python
def delete_front(self):
    if len(self.items) == 0:
        raise Exception("Deque is empty")
    return self.items.pop(0)
```

### 📌 Step 5: Delete from Rear

```python
def delete_rear(self):
    if len(self.items) == 0:
        raise Exception("Deque is empty")
    return self.items.pop()
```

---

## 🔹 12. Example Usage

```python
dq = Deque()

dq.insert_rear(10)
dq.insert_front(20)
dq.insert_rear(30)
dq.insert_front(50)

print(dq.delete_rear())   # 30
print(dq.delete_front())  # 50
print(dq.delete_front())  # 20
print(dq.delete_rear())   # 10
```

---

## 🔹 13. Key Difference

| Feature | Stack    | Queue      | Deque     |
| ------- | -------- | ---------- | --------- |
| Order   | LIFO     | FIFO       | Both      |
| Insert  | Top only | Rear only  | Both ends |
| Delete  | Top only | Front only | Both ends |
